# Oscar — 온라인

외부망에서 구글 로그인 후 어디서든 업무카드를 보고 고치는 버전입니다.
이 저장소에는 **프로그램 코드만** 있고, 업무카드 내용은 들어 있지 않습니다.
내용은 로그인한 계정만 읽고 쓸 수 있는 Firebase(Firestore)에만 저장됩니다.

## 1. Firebase 준비 (한 번만)
1. https://console.firebase.google.com → **프로젝트 추가**(입환게임과는 별도 프로젝트 권장, 무료 Spark 요금제)
2. **빌드 → Authentication → 시작하기 → Google** 사용 설정(지원 이메일 선택)
3. **빌드 → Firestore Database → 데이터베이스 만들기**(프로덕션 모드, 위치 `asia-northeast3` 서울 또는 `asia-northeast1`)
4. **Firestore → 규칙** 탭에 `firestore.rules` 내용을 붙여 넣되 `YOUR_EMAIL@gmail.com`을 본인 구글 계정으로 바꾸고 **게시**
5. **프로젝트 설정 → 일반 → 내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값을 `cloud-config.js`에 붙여 넣기
6. **Authentication → 설정 → 승인된 도메인**에 `계정명.github.io` 추가

## 2. 배포 (GitHub Pages)
저장소 **Settings → Pages → Deploy from a branch → main / (root)** 선택.
몇 분 뒤 `https://계정명.github.io/저장소이름/` 에서 열립니다.

## 3. 처음 데이터 올리기
1. 사내(오프라인) 프로그램: **💾 백업 → ⬇ 동기화파일 다운로드**(이미지·첨부 포함)
2. 온라인 사이트에 로그인 → **💾 백업(폰은 더보기) → ⬆ 동기화파일 업로드** → 합치기 실행
3. 그러면 모든 카드가 클라우드에 올라가고, 이후 어느 기기에서 고쳐도 서로 반영됩니다.

## 알아둘 점
- 같은 항목을 두 기기에서 동시에 고치면 더 최근 값이 남습니다(다른 항목은 둘 다 살아남음).
- 이미지는 700KB 이하로 줄여 저장합니다. 그 이상(큰 첨부 파일)은 올린 기기에서만 보입니다.
- 영구 삭제한 카드는 다른 기기로 전달되지 않습니다. 삭제는 휴지통(복구 가능)을 쓰세요.
- 폰에서는 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 설치할 수 있습니다.
- 인터넷이 끊겨도 그 기기에서는 계속 쓸 수 있고, 연결되면 자동으로 반영됩니다.

## 관리자 / 권한
- 최고 관리자 이메일은 공개 저장소에 두지 않고 Firebase 규칙(`firestore.rules`의 `ADMIN_EMAIL@gmail.com` 자리)에만 넣습니다.
- 로그인 후 상단 클라우드 배지 → 👥 사용자·권한 관리 에서 이메일별 보기/편집/관리자를 부여·제거합니다.
- 규칙 변경 후 Firebase 콘솔 → Firestore → 규칙 → 게시.

## 홈 화면 아이콘
`manifest.webmanifest`와 `icons/`로 앱 아이콘이 적용됩니다. 기존 바로가기는 삭제 후 Chrome 메뉴 → 홈 화면에 추가로 다시 설치하세요.
